One sentence, at most 280 characters, that brings back a childhood memory — rain on a tin roof, shallots frying in Grandma's kitchen, small enough to hide under the table.

Run it: `node main.ts` writes the sentence to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
